서버에서 전사 결과가 실시간으로 여기에 표시됩니다...

⚠️ 사용 방법

  1. Django 서버가 실행 중인지 확인하세요: python manage.py runserver
  2. WebSocket URL을 확인하세요: ws://localhost:8000/ws/audio/
  3. "STT 시작" 버튼을 클릭하고 마이크 권한을 허용하세요.
  4. 말하면 실시간으로 전사 결과가 표시됩니다.
  5. 브라우저 콘솔(F12)에서 자세한 로그를 확인할 수 있습니다.
