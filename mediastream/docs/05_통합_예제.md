## 5.1 전체 파이프라인 개요

### 데이터 흐름

```
[마이크]
  ↓
[getUserMedia] → MediaStream
  ↓
[MediaRecorder] → Blob (청크)
  ↓
[Blob → ArrayBuffer 변환]
  ↓
[WebSocket] → Django 서버
  ↓
[STT 처리] → 전사 결과
  ↓
[WebSocket] → 클라이언트
```

### 각 단계의 역할

1. **getUserMedia**: 마이크에서 오디오 스트림 가져오기
2. **MediaRecorder**: 스트림을 Blob 청크로 수집
3. **Blob → ArrayBuffer**: WebSocket 전송을 위한 형식 변환
4. **WebSocket**: 실시간으로 서버에 전송
5. **Django 서버**: 오디오 수신 및 STT 처리
6. **응답**: 전사 결과를 클라이언트로 전송

## 5.2 완성형 클라이언트 코드

### 전체 통합 클래스

모든 기능을 통합한 완성형 클래스입니다:

```typescript
class RealTimeAudioSTTClient {
  private wsManager: WebSocketManager;
  private mediaRecorder: MediaRecorder | null = null;
  private stream: MediaStream | null = null;
  private sequenceNumber = 0;
  private isStreaming = false;
  private config: ClientConfig;

  constructor(wsUrl: string, config: ClientConfig = {}) {
    this.wsManager = new WebSocketManager(wsUrl);
    this.config = {
      timeslice: 100,
      mimeType: "audio/webm;codecs=opus",
      audioBitsPerSecond: 128000,
      autoReconnect: true,
      ...config,
    };
    this.setupMessageHandlers();
  }

  async start(): Promise<void> {
    if (this.isStreaming) {
      throw new Error("이미 스트리밍 중입니다.");
    }

    try {
      // 1. WebSocket 연결
      await this.wsManager.connect();

      // 2. 미디어 스트림 가져오기
      await this.setupMediaStream();

      // 3. MediaRecorder 설정
      await this.setupMediaRecorder();

      // 4. 시작 메시지 전송
      this.sendStartMessage();

      // 5. 녹화 시작
      if (this.mediaRecorder) {
        this.mediaRecorder.start(this.config.timeslice);
        this.isStreaming = true;
        this.onStart?.();
      }
    } catch (error) {
      console.error("스트리밍 시작 실패:", error);
      this.onError?.(error);
      throw error;
    }
  }

  private async setupMediaStream(): Promise<void> {
    const constraints: MediaStreamConstraints = {
      audio: {
        echoCancellation: true,
        noiseSuppression: true,
        autoGainControl: true,
      },
    };

    this.stream = await navigator.mediaDevices.getUserMedia(constraints);
  }

  private async setupMediaRecorder(): Promise<void> {
    if (!this.stream) {
      throw new Error("MediaStream이 없습니다.");
    }

    const mimeType = this.config.mimeType || this.getBestMimeType();

    this.mediaRecorder = new MediaRecorder(this.stream, {
      mimeType,
      audioBitsPerSecond: this.config.audioBitsPerSecond,
    });

    this.mediaRecorder.ondataavailable = async (event: BlobEvent) => {
      if (event.data && event.data.size > 0 && this.wsManager.isConnected()) {
        await this.sendAudioChunk(event.data);
      }
    };

    this.mediaRecorder.onerror = (event: MediaRecorderErrorEvent) => {
      console.error("MediaRecorder 에러:", event.error);
      this.onError?.(event.error);
    };
  }

  private async sendAudioChunk(blob: Blob): Promise<void> {
    try {
      const arrayBuffer = await blob.arrayBuffer();

      const metadata = {
        type: "audio",
        sequence: this.sequenceNumber++,
        timestamp: Date.now(),
        size: arrayBuffer.byteLength,
        mimeType: blob.type,
      };

      // 메타데이터 전송
      this.wsManager.send(JSON.stringify(metadata));

      // 오디오 데이터 전송
      this.wsManager.send(arrayBuffer);

      this.onChunkSent?.(metadata);
    } catch (error) {
      console.error("청크 전송 실패:", error);
      this.onError?.(error);
    }
  }

  private sendStartMessage(): void {
    if (!this.mediaRecorder) {
      return;
    }

    const message = {
      type: "start",
      mimeType: this.mediaRecorder.mimeType,
      config: {
        timeslice: this.config.timeslice,
        audioBitsPerSecond: this.config.audioBitsPerSecond,
      },
    };

    this.wsManager.send(JSON.stringify(message));
  }

  private setupMessageHandlers(): void {
    this.wsManager.onMessage((response: ServerResponse) => {
      switch (response.type) {
        case "transcription":
          this.onTranscription?.(response.data || "");
          break;
        case "error":
          this.onError?.(new Error(response.data || "서버 에러"));
          break;
        case "ack":
          this.onAck?.(response.sequence);
          break;
      }
    });
  }

  stop(): void {
    if (!this.isStreaming) {
      return;
    }

    if (this.mediaRecorder) {
      this.mediaRecorder.stop();
      this.mediaRecorder = null;
    }

    if (this.stream) {
      this.stream.getTracks().forEach((track) => track.stop());
      this.stream = null;
    }

    const endMessage = { type: "end" };
    this.wsManager.send(JSON.stringify(endMessage));
    this.wsManager.close();

    this.isStreaming = false;
    this.sequenceNumber = 0;
    this.onStop?.();
  }

  // 콜백 함수들
  onStart?: () => void;
  onStop?: () => void;
  onTranscription?: (text: string) => void;
  onError?: (error: unknown) => void;
  onChunkSent?: (metadata: AudioChunkMetadata) => void;
  onAck?: (sequence: number) => void;

  private getBestMimeType(): string {
    const types = [
      "audio/webm;codecs=opus",
      "audio/webm",
      "audio/ogg;codecs=opus",
    ];

    for (const type of types) {
      if (MediaRecorder.isTypeSupported(type)) {
        return type;
      }
    }

    return "";
  }
}
```

### ASGI 설정

```python
# asgi.py
import os
from django.core.asgi import get_asgi_application
from channels.routing import ProtocolTypeRouter, URLRouter
from channels.auth import AuthMiddlewareStack
import myapp.routing

os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'myproject.settings')

application = ProtocolTypeRouter({
    "http": get_asgi_application(),
    "websocket": AuthMiddlewareStack(
        URLRouter(
            myapp.routing.websocket_urlpatterns
        )
    ),
})
```

### WebSocket Consumer

```python
# consumers.py
import json
import base64
from channels.generic.websocket import AsyncWebsocketConsumer
from asgiref.sync import sync_to_async

class AudioSTTConsumer(AsyncWebsocketConsumer):
    async def connect(self):
        await self.accept()
        self.sequence = 0
        self.audio_buffer = bytearray()
        print("WebSocket 연결됨")

    async def disconnect(self, close_code):
        print(f"WebSocket 연결 종료: {close_code}")

    async def receive(self, text_data=None, bytes_data=None):
        if text_data:
            # JSON 메시지 처리
            try:
                data = json.loads(text_data)
                await self.handle_text_message(data)
            except json.JSONDecodeError:
                print("JSON 파싱 실패")

        elif bytes_data:
            # 이진 데이터 처리 (오디오 청크)
            await self.handle_audio_chunk(bytes_data)

    async def handle_text_message(self, data):
        message_type = data.get('type')

        if message_type == 'start':
            print(f"녹음 시작: {data.get('mimeType')}")
            self.audio_buffer = bytearray()
            self.sequence = 0

        elif message_type == 'end':
            print("녹음 종료")
            # 마지막 버퍼 처리
            if len(self.audio_buffer) > 0:
                await self.process_audio(self.audio_buffer)
            self.audio_buffer = bytearray()

        elif message_type == 'audio':
            # 메타데이터만 받음 (실제 데이터는 bytes_data로)
            sequence = data.get('sequence')
            size = data.get('size')
            print(f"오디오 청크 메타데이터: sequence={sequence}, size={size}")

    async def handle_audio_chunk(self, bytes_data):
        # ArrayBuffer를 bytes로 받음
        self.audio_buffer.extend(bytes_data)
        self.sequence += 1

        # 일정 크기마다 또는 주기적으로 STT 처리
        if len(self.audio_buffer) >= 16000:  # 예: 16KB마다
            await self.process_audio(self.audio_buffer)
            self.audio_buffer = bytearray()

    async def process_audio(self, audio_data):
        try:
            # STT 처리 (예: Google Speech-to-Text, Whisper 등)
            transcription = await self.run_stt(audio_data)

            # 결과를 클라이언트로 전송
            await self.send(text_data=json.dumps({
                'type': 'transcription',
                'data': transcription,
                'sequence': self.sequence,
            }))

        except Exception as e:
            print(f"STT 처리 실패: {e}")
            await self.send(text_data=json.dumps({
                'type': 'error',
                'data': str(e),
            }))

    @sync_to_async
    def run_stt(self, audio_data):
        # 여기에 실제 STT 로직 구현
        # 예: Google Speech-to-Text API 호출
        # 또는 Whisper 모델 사용

        # 임시로 더미 응답
        return "전사 결과가 여기에 표시됩니다."
```

### 메시지 형식

#### 1. 시작 메시지 (클라이언트 → 서버)

```json
{
  "type": "start",
  "mimeType": "audio/webm;codecs=opus",
  "config": {
    "timeslice": 100,
    "audioBitsPerSecond": 128000
  }
}
```

#### 2. 오디오 청크 메타데이터 (클라이언트 → 서버)

```json
{
  "type": "audio",
  "sequence": 0,
  "timestamp": 1234567890,
  "size": 1024,
  "mimeType": "audio/webm"
}
```

**이후 바로 이진 데이터 (ArrayBuffer) 전송**

#### 3. 종료 메시지 (클라이언트 → 서버)

```json
{
  "type": "end"
}
```

#### 4. 전사 결과 (서버 → 클라이언트)

```json
{
  "type": "transcription",
  "data": "안녕하세요",
  "sequence": 0
}
```

#### 5. 에러 메시지 (서버 → 클라이언트)

```json
{
  "type": "error",
  "data": "에러 메시지"
}
```

#### 6. 확인 메시지 (서버 → 클라이언트)

```json
{
  "type": "ack",
  "sequence": 0
}
```

  static handleGetUserMediaError(error: unknown): void {

        case "NotFoundError":
          alert("마이크를 찾을 수 없습니다.");
          break;

## 5.6 성능 최적화

### 클라이언트 최적화

1. **Timeslice 조정**: 너무 작으면 오버헤드 증가, 너무 크면 지연 증가

   - 권장: 50-200ms

2. **비트레이트 조정**: 품질과 대역폭의 균형

   - 고품질: 128 kbps
   - 일반: 64 kbps
   - 저품질: 32 kbps

3. **버퍼 관리**: 메모리 누수 방지

```typescript
// 청크를 전송 후 즉시 정리
mediaRecorder.ondataavailable = async (event: BlobEvent) => {
  const arrayBuffer = await event.data.arrayBuffer();
  websocket.send(arrayBuffer);
  // 명시적으로 정리 (가비지 컬렉션 힌트)
};
```

### 서버 최적화

1. **비동기 처리**: STT를 비동기로 처리하여 블로킹 방지

2. **배치 처리**: 여러 청크를 모아서 한 번에 처리

3. **캐싱**: 동일한 오디오에 대한 결과 캐싱

## 5.7 실전 배포 고려사항

### 보안

1. **WSS 사용**: 프로덕션에서는 반드시 `wss://` 사용

2. **인증**: WebSocket 연결 시 사용자 인증

3. **CORS 설정**: 적절한 CORS 정책 설정

### 확장성

1. **로드 밸런싱**: 여러 서버로 부하 분산

2. **Redis 채널 레이어**: Django Channels에서 Redis 사용

3. **모니터링**: 연결 수, 처리량 모니터링

### 트러블슈팅

#### 문제: WebSocket 연결 실패

**원인**:

- 서버가 실행되지 않음
- URL이 잘못됨
- 방화벽/프록시 문제

**해결**:

- 서버 상태 확인
- URL 확인 (ws:// vs wss://)
- 네트워크 설정 확인

#### 문제: 오디오가 전송되지 않음

**원인**:

- MediaRecorder가 시작되지 않음
- WebSocket이 연결되지 않음
- Blob → ArrayBuffer 변환 실패

**해결**:

- 각 단계별 로그 확인
- 브라우저 콘솔에서 에러 확인

#### 문제: 전사 결과가 나오지 않음

**원인**:

- STT 서비스 에러
- 오디오 형식 문제
- 서버 처리 실패

**해결**:

- 서버 로그 확인
- 오디오 형식 확인
- STT 서비스 상태 확인
