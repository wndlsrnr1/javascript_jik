# 부록: 용어집 및 참고 자료

## 📚 주요 용어 정리

### MediaStream 관련

#### MediaStream

**정의**: 실시간으로 오디오/비디오 데이터를 전달하는 스트림 객체  
**비유**: 수도관처럼 데이터가 흐르는 통로  
**사용**: `navigator.mediaDevices.getUserMedia()`로 생성

#### MediaStreamTrack

**정의**: MediaStream을 구성하는 개별 트랙 (오디오 또는 비디오)  
**비유**: 스트림 안의 개별 파이프  
**종류**: AudioTrack, VideoTrack

#### getUserMedia()

**정의**: 브라우저 API로 마이크/카메라 접근을 요청하는 함수  
**반환**: Promise<MediaStream>  
**보안**: Secure Context (HTTPS)에서만 사용 가능

#### Constraints

**정의**: 미디어 요청 시 원하는 조건을 지정하는 객체  
**예시**: `{ audio: true, video: { width: 1280, height: 720 } }`  
**키워드**: `ideal`, `min`, `max`, `exact`

### MediaRecorder 관련

#### MediaRecorder

**정의**: MediaStream의 데이터를 수집하고 인코딩하는 인터페이스  
**비유**: 녹음기처럼 스트림을 기록하는 도구  
**생성**: `new MediaRecorder(stream, options)`

#### MIME Type

**정의**: 데이터 형식을 나타내는 문자열  
**예시**: `audio/webm`, `audio/webm;codecs=opus`  
**확인**: `MediaRecorder.isTypeSupported()`

#### Codec

**정의**: 데이터를 압축/압축 해제하는 알고리즘  
**예시**: Opus, PCM, AAC  
**역할**: 파일 크기와 품질의 균형

#### Timeslice

**정의**: 데이터를 주기적으로 나누어 받는 간격 (밀리초)  
**예시**: `mediaRecorder.start(100)` - 100ms마다 청크 수집  
**용도**: 실시간 전송에 유용

#### Blob

**정의**: 파일과 유사한 불변 바이너리 데이터 객체  
**특징**: MIME 타입 정보 포함, 크기 정보 있음  
**사용**: 파일 다루기, URL 생성

#### BlobEvent

**정의**: MediaRecorder가 데이터 청크를 생성할 때 발생하는 이벤트  
**속성**: `event.data` (Blob)  
**이벤트**: `ondataavailable`

### WebSocket 관련

#### WebSocket

**정의**: 브라우저와 서버 간 양방향 실시간 통신 프로토콜  
**비유**: 전화 통화처럼 실시간으로 대화  
**프로토콜**: `ws://` (일반), `wss://` (보안)

#### WebSocket 상태

- **CONNECTING (0)**: 연결 중
- **OPEN (1)**: 연결됨
- **CLOSING (2)**: 닫는 중
- **CLOSED (3)**: 닫힘

#### ArrayBuffer

**정의**: 고정 길이의 원시 바이너리 데이터 버퍼  
**특징**: 직접 접근 불가, TypedArray로 접근  
**용도**: 메모리 직접 조작, 네트워크 전송

#### TypedArray

**정의**: ArrayBuffer를 특정 타입으로 해석하는 뷰  
**종류**: Uint8Array, Int16Array, Float32Array 등  
**역할**: 바이너리 데이터를 숫자 배열로 다루기

### 데이터 변환 관련

#### Blob → ArrayBuffer

**방법**: `await blob.arrayBuffer()`  
**용도**: WebSocket으로 이진 데이터 전송

#### ArrayBuffer → Blob

**방법**: `new Blob([buffer], { type: mimeType })`  
**용도**: 파일 다운로드, URL 생성

### 에러 관련

#### NotAllowedError

**원인**: 사용자가 마이크/카메라 권한 거부  
**해결**: 브라우저 설정에서 권한 허용

#### NotFoundError

**원인**: 요청한 미디어 장치가 없음  
**해결**: 장치 연결 확인

#### NotReadableError

**원인**: 다른 프로그램이 장치 사용 중  
**해결**: 다른 프로그램 종료

#### OverconstrainedError

**원인**: 요청한 Constraints를 만족하는 장치 없음  
**해결**: Constraints 완화

#### InvalidStateError

**원인**: 잘못된 상태에서 메서드 호출  
**예시**: 이미 정지된 MediaRecorder에 stop() 호출

### Django 관련

#### Django Channels

**정의**: Django에서 WebSocket을 지원하는 라이브러리  
**역할**: ASGI를 통한 비동기 WebSocket 처리

#### ASGI

**정의**: Asynchronous Server Gateway Interface  
**역할**: 비동기 웹 애플리케이션과 서버 간 인터페이스

#### Consumer

**정의**: WebSocket 연결을 처리하는 클래스  
**역할**: 메시지 수신, 처리, 전송

## ❓ 자주 묻는 질문 (FAQ)

### Q1: getUserMedia()가 작동하지 않아요.

**A**: 다음을 확인하세요:

- HTTPS 또는 localhost에서 실행 중인지
- 브라우저에서 마이크 권한이 허용되었는지
- 마이크가 연결되어 있는지

### Q2: MediaRecorder가 지원하지 않는 형식이라고 나와요.

**A**: `MediaRecorder.isTypeSupported()`로 지원 여부를 확인하고, 지원하는 형식을 사용하세요.

### Q3: WebSocket 연결이 실패해요.

**A**: 다음을 확인하세요:

- 서버가 실행 중인지
- URL이 올바른지 (ws:// 또는 wss://)
- 방화벽/프록시 설정

### Q4: 오디오가 전송되지 않아요.

**A**: 다음을 확인하세요:

- MediaRecorder가 시작되었는지 (`state === 'recording'`)
- WebSocket이 연결되었는지 (`readyState === OPEN`)
- Blob → ArrayBuffer 변환이 성공했는지

### Q5: 전사 결과가 나오지 않아요.

**A**: 다음을 확인하세요:

- Django 서버가 오디오를 수신하는지
- STT 서비스가 정상 작동하는지
- 서버 로그에서 에러 확인
